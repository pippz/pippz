## 01 / selected work

### [Red Odyssey](https://github.com/nczeta/red-odyssey)

<sub>NASA SPACE APPS CHALLENGE 2026 &nbsp; · &nbsp; MARS EXPLORATION</sub>

An interactive exploration of Jezero Crater on Mars, combining geospatial data, multiple 2D map views and 3D terrain visualization.

My contribution focused on creating and styling the maps in **QGIS**, preparing geospatial layers, and helping integrate **GeoTIFF** and **GeoJSON** data into the JavaScript website.

`QGIS` &nbsp; `OpenLayers` &nbsp; `GeoTIFF` &nbsp; `GeoJSON` &nbsp; `JavaScript`
